# Phoenix Torrent

Быстрый и лёгкий торрент-клиент для Windows: один exe-файл около 13 МБ, без установки.

Движок — [librqbit](https://github.com/ikatson/rqbit) (Rust), окно — [Tauri 2](https://tauri.app), интерфейс — обычные HTML/CSS/JS без сборщиков.

## Скачать

Готовый `PhoenixTorrent.exe` лежит на странице [Releases](https://github.com/JakeMorgan/PhoenixTorrent/releases/latest). Больше ничего не нужно: скачайте и запустите.

Требуется Windows 10 или 11. Окно рисуется через системный компонент Microsoft Edge WebView2 — в Windows 11 он есть всегда, в Windows 10 ставится вместе с Edge.

## Возможности

- **Добавление раздач**: magnet-ссылки, URL и `.torrent`-файлы — кнопкой, через Ctrl+V или перетаскиванием в окно. Несколько файлов или ссылок встают в очередь.
- **Выбор файлов**: перед загрузкой и на ходу. Невыбранные файлы не создаются на диске пустышками.
- **Скачанное сразу доступно**: клиент не держит готовые файлы открытыми на запись, их можно запускать и перемещать, пока раздача активна.
- **Перепроверка данных**: кнопка в строке раздачи заново сверяет хеши с файлами на диске.
- **Сеть**: DHT, uTP, UPnP, лимиты скорости. Если настроенный порт занят, берётся свободный, и это видно в строке состояния.
- **Возобновление**: раздачи продолжаются после перезапуска без повторной проверки.
- **Интеграция с Windows**: сворачивание в трей, ассоциация с `.torrent` и `magnet:` (кнопка в настройках), один экземпляр программы.
- **Оформление**: тёмная и светлая тема по настройке системы.

## Что стоит знать

- **Соседние файлы**: BitTorrent качает кусками, и кусок на границе захватывает соседний файл. Поэтому рядом с выбранным файлом может появиться частично скачанный невыбранный — так ведут себя все клиенты.
- **Данные программы**: настройки и список раздач лежат в `%APPDATA%\app.phoenix.torrent`, а не рядом с exe. Сам exe можно свободно перемещать.
- **Ассоциации**: записываются для текущего пользователя и указывают на путь к exe. После перемещения программы достаточно один раз запустить её с нового места.

## Сборка

Нужны [Rust](https://rustup.rs) и Visual Studio Build Tools с компонентом C++.

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

Скрипт кладёт `PhoenixTorrent.exe` в корень проекта. Вручную то же самое:

```powershell
cd src-tauri
cargo build --release --features custom-protocol
```

Тест хранилища качает небольшой файл из открытой раздачи, поэтому ему нужна сеть:

```powershell
cd src-tauri
cargo test --features custom-protocol -- --ignored --nocapture
```

## Выпуск версии

Релиз собирает GitHub Actions при появлении тега `v*`. Поднимите версию в `src-tauri/Cargo.toml` и `src-tauri/tauri.conf.json`, закоммитьте и отправьте тег:

```powershell
git tag v1.1.0
git push origin main v1.1.0
```

Каждый push в `main` и каждый pull request тоже собираются; exe лежит в артефактах запуска.

## Структура

- `src-tauri/src/main.rs` — бэкенд: сессия librqbit, команды для интерфейса, трей, ассоциации;
- `src-tauri/src/lazy_storage.rs` — файловое хранилище: создаёт файлы при первой записи и отпускает их после неё;
- `ui/` — интерфейс;
- `.github/workflows/build.yml` — сборка и публикация релизов.
